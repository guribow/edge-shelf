# EdgeShelf

[English](README.en.md)

画面の端に「棚」を出して、ファイルや画像、テキスト、リンクを一時的に置いておけるメニューバーアプリです。Dropshelf を参考に作りました。

ものをドラッグして画面の左端か右端へ持っていくと、棚がすべり出てきます。いったん棚に置いておけば、別のウインドウやタブ、フルスクリーンのアプリ、別の Spaces へ移ってから取り出せます。

- macOS 13 以降で動きます（Apple シリコン・Intel）。macOS 26 以降では、棚がリキッドグラスの見た目になります。
- 日本語と英語に対応しています。Mac の言語設定に合わせて切り替わります。

## ダウンロードと入れ方

[Releases](https://github.com/guribow/edge-shelf/releases/latest) から zip をダウンロードしてください。`EdgeShelf-<版>-ja.zip` には日本語の説明書、`-en.zip` には英語の説明書が入っています。アプリはどちらも同じです。

1. zip を開き、EdgeShelf.app を「アプリケーション」フォルダへ移します。
2. ダブルクリックすると「開けませんでした」という警告が出るので、「完了」で閉じます。App Store 以外のアプリなので、最初の 1 回だけ出ます。
3. システム設定の「プライバシーとセキュリティ」を開き、下のほうにある「このまま開く」を押してパスワードを入れます。
4. もう一度ダブルクリックして、「開く」を押します。

メニューバーにトレイのアイコンが出たら準備完了です。新しい版に入れ替えたときは、2〜4 をもう一度行ってください。

## 使い方

- **置く**：ドラッグしたまま画面の左端か右端で少し止めると、棚が開きます。マウスを少し動かしてから離してください。⌘V でクリップボードの中身を置いたり、ほかのアプリの右クリックから「サービス」→「EdgeShelf に送る」で送ったりもできます。
- **取り出す**：棚のものを、使いたい場所へドラッグします。取り出したものは棚から消えます。
- 棚からマウスが離れると、画面の端の小さな「つまみ」に縮みます。つまみにマウスを乗せると、また開きます。つまみが見つからないときは、メニューバーのアイコンを押すと光って場所が分かります。
- 棚はいくつでも作れます。棚のない高さで端へドラッグすると、新しい棚ができます。
- 右クリックで、開く・プレビュー・Finder で表示・コピー・取り除くが選べます。スペースキーで Quick Look が開きます。
- ⌘クリックや⇧クリックで、複数を選べます。
- 棚の見出しにあるゴミ箱のボタンで、棚を空にできます。元のファイルは消えません。
- メニューバーのアイコンから、つまみの色、点滅の色、棚が開くまでの時間、ログイン時に起動を設定できます。

## 気をつけること

- 棚に置いたファイルはコピーではなく、元のファイルを指しているだけです。棚から Finder へドラッグすると、Finder で直接ドラッグしたときと同じく、同じディスクの中なら移動になります。
- 写真アプリや Web ページの画像は、`~/Library/Application Support/EdgeShelf` にファイルとして保存します。
- データを外部に送ることはありません。

## 消し方

1. メニューバーのアイコン →「終了」
2. EdgeShelf.app をゴミ箱に入れます。
3. 棚の中身も消すときは、`~/Library/Application Support/EdgeShelf` をゴミ箱に入れます。

## ソースからビルドする

Xcode（swiftc）が必要です。

```bash
./build.sh   # ビルドして ~/Applications/EdgeShelf.app に入れる
./dist.sh    # dist/ に配布用の zip を作る
```
