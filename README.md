# EdgeShelf

画面の端に、ものを一時的に置いておける「棚」を出すメニューバーアプリ。Dropshelf を参考にした自作版。

ファイル・画像・テキスト・リンクを画面の左右の端へドラッグすると、棚がすべり出てくる。そこに置いておけば、別のウインドウやタブ、フルスクリーンのアプリ、別の操作スペースへ持っていくときに、元の場所と行き先を同時に開いておく必要がない。

- 作成：2026-09-26
- 動作確認：Mac mini（Apple Silicon）、macOS 27.2、5K ディスプレイ 1 枚。合成マウスイベントで、端へのドラッグで棚が出ること、ファイル・テキスト・画像データを置けること、棚から別のアプリへドラッグして取り出せることを確認
- 動く環境：macOS 13 以降（Apple シリコン・Intel）。macOS 26 以降では、棚とつまみがリキッドグラスになる。13〜15 では従来の半透明の見た目（実機では未確認）
- 言語：日本語・英語。Mac の言語設定に合わせて自動で切り替わる。EdgeShelf だけ言語を変えたいときは、システム設定 →「一般」→「言語と地域」→「アプリケーション」で指定する

## 使い方

### 棚を出す・置く

- 何かをドラッグしたまま、画面の**左端か右端**でマウスを一瞬止める → 棚がすべり出るので、その上で離す
- 棚がない高さで端へ持っていくと、そこに新しい棚ができる。棚はいくつでも作れ、複数の画面でも使える（となりの画面とつながっている辺には作れない）
- 何も置かずにドラッグをやめると、仮の棚は消える
- 端に来てから棚が開き始めるまでの時間は、メニューバーの「端で開くまでの時間」で ms 単位で変えられる（既定は 200 ms）。すでにある棚のつまみの上へドラッグしたときも同じ時間だけ待つ

### ほかのアプリの右クリックから送る

macOS の「サービス」に「EdgeShelf に送る」が加わる。

- Finder：ファイルやフォルダを右クリック →「クイックアクション」または「サービス」→「EdgeShelf に送る」
- そのほかのアプリ：選んだテキストやリンクを右クリック →「サービス」→「EdgeShelf に送る」

送ったものは、最後にものを置いた棚に入り、届いたのが分かるよう少しのあいだ棚が開く。棚が 1 つもなければ、マウスのある画面の右端に新しい棚ができる。メニューに出ないときは、システム設定の「キーボード」→「キーボードショートカット」→「サービス」で「EdgeShelf に送る」にチェックを入れる。

### 棚を使う

- 棚は 272×366 で、4 件（2 段）まではスクロールせずに入る。背景はメニューと同じ、後ろがうっすら透けるガラスの素材。マウスが棚から離れると、棚の上端にそろえた小さなつまみ（数字は件数）に縮む。つまみは棚と同じガラスの素材で、設定した色はガラスの上に重ねる（透明度を下げるとガラスが透ける）。つまみにマウスを乗せるかクリックすると開く
- 置いたものは、そのままドラッグして好きな場所へ運べる。**取り出すと棚から消える**（移動）。ドロップをやめたときは残る
- ファイルとテキスト・リンクを一緒に Finder（デスクトップを含む）へ落としたときは、ファイルだけが消え、テキストとリンクは棚に残る。ほかのアプリへ落としたときは全部消える（macOS はドロップ先がどれを受け取ったかを教えてくれないため、ドロップ先のアプリで見分けている）
- 複数選択：⌘クリックで 1 つずつ、⇧クリックで範囲、何もないところからドラッグで四角く囲む。⇧＋矢印キー、⌘A も使える。選んだものは、まとめてドラッグ・コピー・取り除ける
- スペースキーで Quick Look のプレビュー。もう一度スペースで閉じる。プレビュー中に矢印キーで選択を動かすと、表示も切り替わる。プレビューを開くと EdgeShelf が前面になり（キー入力が下のアプリへ流れないように）、閉じたあとも棚でキー入力を受け続ける（続けてスペースでまた開ける）。棚が縮むと元のアプリに戻る
- 置いたものは 2 列のタイルで並び、写真やファイルは大きなサムネイル、その下に名前が出る。長い名前も省略せず折り返して全部出す（テキストのメモは 6 行まで）
- 一度に複数のファイルを置くと 1 つのタイルにまとまり（赤い数字が件数）、まとめて 1 回でドラッグできる。右クリックの「ばらす」で 1 つずつに分けられる
- 見出しの左の重なったアイコンをドラッグすると、棚のものをすべてまとめて運べる
- 見出しの何もないところをドラッグすると、棚を上下に動かせる
- 棚から別の棚へドラッグすると、移動になる

右クリックのメニュー（複数選択中は選んだものすべてが対象）：開く／プレビュー／Finder で表示／コピー／ばらす（まとめた項目を 1 つだけ選んだとき）／取り除く

棚をクリックしたあとのキー操作：

| キー | 動作 |
| --- | --- |
| ⌘V | クリップボードの中身を棚に置く |
| space | プレビュー（Quick Look）を開く・閉じる |
| ⌘C | 選んだもの（なければ全部）をクリップボードへ |
| ⌘A | すべて選ぶ |
| delete | 選んだものを取り除く |
| return | 選んだものを開く |
| ← → ↑ ↓ | 選ぶ項目を変える（⇧ で範囲を広げる） |
| esc | 棚を縮める |

見出しの右のゴミ箱ボタン：1 クリックで棚のものをすべて取り除き、棚を閉じる（元のファイルは消えない。写真などから作ったファイルは消える）

見出しの右の「…」：クリップボードから貼り付け／すべてコピー／すべて取り除いて棚を閉じる

### メニューバー

アイコン：どれかの棚にものが入っているときは塗りつぶしのトレイ `tray.full.fill`、すべて空のときは線だけのトレイ `tray`。アイコンを押してメニューを開いている間は、各棚のつまみの周り（輪の部分だけ）がアクセントカラー（青）でゆっくり脈打つように光り、どこに棚があるか分かる

```
EdgeShelf について      ← 標準の「このアプリについて」（バージョン・著作権）
──────────
右の棚：3 件            ← クリックでその棚を開く
すべての棚を空にする…   ← 棚が 2 つ以上あるときだけ出る。確認のあとで全部取り除く
──────────
クリップボードを新しい棚に置く
──────────
端で開くまでの時間：200 ms  ▸   ← 0〜1000 ms から選ぶか、「カスタム…」で 0〜5000 ms を入力
つまみの色…              ← macOS 標準のカラーパネルで選ぶ。その場ですべてのつまみに反映
点滅の色…                ← 同じく。選んでいる間はつまみが光って見える
色を標準に戻す            ← 色を変えたときだけ出る
ログイン時に起動
終了                ⌘Q
```

## 何をどう置くか

| ドロップしたもの | 棚での扱い |
| --- | --- |
| Finder のファイル・フォルダ | 元のファイルへの参照。コピーはしない |
| 写真アプリの写真、Web ページの画像 | ファイルとして受け取る（「解決」する）。保存先は下記 |
| Web のリンク | リンク（ドラッグ・コピーすると URL になる） |
| 選んだ文字 | テキスト |

- ファイルは参照なので、棚に置いたあと Finder で移動・名前変更しても追いかける（ブックマークを使っている）。見つからなくなると薄く表示される
- 棚から Finder へファイルをドラッグすると、Finder でファイルを直接ドラッグしたときと同じ動きになる（同じディスク内なら移動、別のディスクならコピー。option キーでコピー）

## 保存場所

- 棚の中身：`~/Library/Application Support/EdgeShelf/shelves.json`
- 写真や Web の画像から作ったファイル：`~/Library/Application Support/EdgeShelf/Files/`

空になった棚は、縮んだときに自動で消える。棚から取り除くと、このアプリが作ったファイル（`Files/` の中にあるもの）だけを消す。元のファイルは消さない。

写真などから作ったファイルを棚から取り出したときは、行き先のアプリがまだ読んでいるかもしれないので、すぐには消さない。どの棚からも使われていないものは、次にアプリを起動したときに片付ける。

## 仕組み

- ほかのアプリでのドラッグは、マウスのグローバル監視と、ドラッグ用の貼り付け板（`NSPasteboard(name: .drag)`）の変化で見分ける。マウスのボタンを押している間と棚が開いている間だけ 1/30 秒ごとに調べ、それ以外は何もしない
- マウスの監視だけなので、アクセシビリティや入力監視の許可は要らない
- 棚は `NSPanel`（アプリを前面にしないパネル）で、すべての操作スペースとフルスクリーンのアプリの上に出る

## ビルド

```bash
./build.sh                  # ビルドして ~/Applications/EdgeShelf.app に入れる（macOS 13 以降、Apple シリコンと Intel の両対応）
swift icon/make-icon.swift  # アプリアイコンを作り直すとき
swift icon/make-icon.swift preview.png  # アイコンを 1024px の PNG で確認するとき
```

## 試してもらう人に配る

```bash
./dist.sh   # ビルドし直して dist/EdgeShelf-<版>-ja.zip と dist/EdgeShelf-<版>-en.zip を作る
```

アプリはどちらも同じもの（日本語・英語入り）で、入れる説明書だけが違う。ja には「はじめにお読みください.txt」、en には「ReadMe.txt」（入れ方・初回の許可の手順・使い方・消し方）。AirDrop やメールなどで渡す。署名は仮のもの（ad-hoc）なので、受け取った人は初回だけ、システム設定の「プライバシーとセキュリティ」で「このまま開く」を押す必要がある。新しい版を渡すたびにこの許可が要る。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `app/Model.swift` | 棚と項目のデータ、保存、ドロップ・クリップボードの読み取り |
| `app/Shelf.swift` | 棚のウインドウと、つまみ・一覧・行のビュー |
| `app/main.swift` | 端へのドラッグの検知、棚の管理、メニューバー |
| `app/Info.plist` | アプリの設定（Dock に出さない） |
| `dist.sh` | 配布用の zip を作るスクリプト |
| `dist/はじめにお読みください.txt` | 日本語版の zip に入れる、使う人向けの説明書 |
| `dist/ReadMe.txt` | 英語版の zip に入れる、使う人向けの説明書 |
| `app/en.lproj/Localizable.strings` | 英語の文字列（日本語の文字列をキーにした対訳） |
| `app/en.lproj/ServicesMenu.strings` | 右クリック「サービス」の項目名の英語 |
| `app/ja.lproj/` | 日本語（コード中の文字列をそのまま使うので中身は空） |
| `icon/make-icon.swift` | アプリアイコンを作るスクリプト（画面の右端から出た棚へ、写真をドラッグして入れる絵） |
