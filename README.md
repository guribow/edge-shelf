# EdgeShelf

[English](README.en.md)

画面の端に「棚」を出して、ファイルや画像、テキスト、リンクを一時的に置いておけるメニューバーアプリです。Dropshelf を参考に作りました。

ものをドラッグして画面の上下左右の端へ持っていくと、棚がすべり出てきます。いったん棚に置いておけば、別のウインドウやタブ、フルスクリーンのアプリ、別の Spaces へ移ってから取り出せます。

- macOS 13 以降で動きます（Apple シリコン・Intel）。macOS 26 以降では、棚がリキッドグラスの見た目になります。
- 日本語と英語に対応しています。Mac の言語設定に合わせて切り替わります。

## ダウンロードと入れ方

[Releases](https://github.com/guribow/edge-shelf/releases/latest) から zip をダウンロードしてください。`EdgeShelf-<版>-ja.zip` には日本語の説明書、`-en.zip` には英語の説明書が入っています。アプリはどちらも同じです。

1. zip を開き、EdgeShelf.app を「アプリケーション」フォルダへ移します。
2. ダブルクリックすると「開けませんでした」という警告が出るので、「完了」で閉じます。App Store 以外のアプリなので、最初の 1 回だけ出ます。
3. システム設定の「プライバシーとセキュリティ」を開き、下のほうにある「このまま開く」を押してパスワードを入れます。
4. もう一度ダブルクリックして、「開く」を押します。

メニューバーに EdgeShelf のアイコンが出たら準備完了です。zip から新しいバージョンに入れ替えたときは、2〜4 をもう一度行ってください。メニューの「アップデート」で入れ替えたときは要りません。

## 使い方

- **置く**：ドラッグしたまま画面の上下左右の端で少し止めると、棚が開きます。マウスを少し動かしてから離してください。⌘V でクリップボードの中身を置いたり、ほかのアプリの右クリックから「サービス」→「EdgeShelf に送る」で送ったりもできます。
- **取り出す**：棚のものを、使いたい場所へドラッグします。取り出したものは棚から消えます。
- 棚からマウスが離れると、画面の端の細い「つまみ」に縮みます。つまみの上でマウスを少し止めるか、⌥ を押しながらつまみに乗せると、また開きます。つまみはクリックを下のアプリに通すので、スクロールバーやメニューバーの邪魔をしません。つまみが見つからないときは、メニューバーのアイコンを押すと光って場所が分かります。
- 棚の上の横棒のあたりをつかんでドラッグすると、端に沿って棚を動かせます。上や下の端の棚は、横に長い形で出ます。
- 棚はいくつでも作れます。棚のない所で端へドラッグすると、新しい棚ができます。
- 棚は、置いたものが少ないうちは小さく、増えるにつれて端に沿って伸びます。
- タイルにマウスを乗せると、ファイルの場所と、画像なら縦横のピクセル数とファイルサイズ、テキストなら文字数が出ます。
- 右クリックで、開く・プレビュー・Finder で表示・コピー・取り除くが選べます。
- 画像は、右クリックの「JPEG に変換」で JPEG にできます。棚の中身が JPEG に置き換わり、元のファイルはそのまま残ります。撮影日時や位置情報も引き継ぎます。スペースキーで Quick Look が開きます。
- ⌘クリックや⇧クリックで、複数を選べます。
- 棚の見出しにあるゴミ箱のボタンで、棚を空にできます。元のファイルは消えません。
- メニューバーのアイコンから、つまみの色、点滅の色、棚が開くまでの時間（置くとき・見るとき）、近づくとつまみを太くするか、ログイン時に起動を設定できます。「すべての設定を標準に戻す…」で、最初の状態に戻せます。
- 「つまみのしま模様」を選ぶと、床屋の看板のように、つまみにしま模様が流れます（最初は「いつも」）。マウスを近づけたときだけにしたり、止めたりもできます。「1 つ目の色…」「2 つ目の色…」で、しまの 2 色とその濃さを変えられます（最初は青と白）。
- 「タイルの大きさ」で、開いた棚のタイルを極小・小・中・大・特大から選べます。
- 新しいバージョンが出ると、メニューバーのアイコンに小さな丸が付きます。メニューの一番上の「バージョン … にアップデート…」を選ぶと、入れ替えて起動し直します。

## ファイルとデータについて

- 棚に置いたファイルはコピーではなく、元のファイルを指しているだけです。棚から Finder へドラッグすると、Finder で直接ドラッグしたときと同じく、同じディスクの中なら移動になります。
- 写真アプリの写真は、元のファイル名とフルサイズで棚に置きます。編集した写真は編集後のものになります。最初の 1 回だけ、写真へのアクセスを許可するか聞かれます。
- 写真アプリの写真や Web ページの画像は、`~/Library/Application Support/EdgeShelf` にファイルとして保存します。
- アップデートの確認のため、1 日 1 回 GitHub に最新のバージョンを問い合わせます。確認は、メニューの「アップデートを自動で確認」で止められます。それ以外にデータを外部に送ることはありません。

## 消し方

1. メニューバーのアイコン →「終了」
2. EdgeShelf.app をゴミ箱に入れます。
3. 棚の中身も消すときは、`~/Library/Application Support/EdgeShelf` をゴミ箱に入れます。

## ソースからビルドする

Xcode（swiftc）が必要です。

```bash
./build.sh   # ビルドして ~/Applications/EdgeShelf.app に入れる
./dist.sh    # dist/ に配布用の zip を作る
```
